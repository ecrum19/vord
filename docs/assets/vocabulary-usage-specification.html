This draft defines a practical vocabulary usage specification for https://w3id.org/vord# (VoRD) so SPARQL endpoint maintainers can advertise machine-readable live endpoint restrictions to users.

This is an unofficial proposal.

Terminology

The key words MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL are to be interpreted as described in RFC 2119 and RFC 8174.

Conformance

A conforming VoRD publisher satisfies all normative requirements in this document.

PREFIX sd:   <http://www.w3.org/ns/sparql-service-description#>
PREFIX vord: <https://w3id.org/vord#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>

Publishing Model

A service description resource of type sd:Service MUST link to one or more restrictions using vord:hasRestriction.

Every quantitative restriction MUST include:

  • a vord:Restriction and a concrete restriction subclass.
  • vord:metric and vord:maxValue.
  • vord:hasScope, vord:enforcement, and vord:hardRestriction.

Priority Profile for Maintainers

  • MUST: vord:RateRestriction, vord:ResultSizeRestriction, vord:ResponseTimeRestriction.
  • SHOULD: vord:ConcurrentRequestsRestriction, vord:QuotaRestriction.
  • MAY: vord:ServerLoadRestriction, vord:CostModelRestriction.

Minimal Example

@prefix ex:   <https://example.org/sparql/> .
@prefix sd:   <http://www.w3.org/ns/sparql-service-description#> .
@prefix vord: <https://w3id.org/vord#> .
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#> .

ex:service a sd:Service ;
  sd:endpoint <https://example.org/sparql> ;
  vord:hasRestriction ex:rate, ex:resultSize, ex:responseTime .

ex:rate a vord:Restriction, vord:RateRestriction ;
  vord:metric vord:requestsPerWindow ;
  vord:maxValue "60"^^xsd:integer ;
  vord:windowDuration "PT1M"^^xsd:duration ;
  vord:hasScope vord:PerClientIP ;
  vord:enforcement vord:RejectRequest ;
  vord:hardRestriction true .

ex:resultSize a vord:Restriction, vord:ResultSizeRestriction ;
  vord:metric vord:resultBindings ;
  vord:maxValue "50000"^^xsd:integer ;
  vord:hasScope vord:PerRequest ;
  vord:enforcement vord:TruncateResult ;
  vord:hardRestriction true .

ex:responseTime a vord:Restriction, vord:ResponseTimeRestriction ;
  vord:metric vord:evaluationTime ;
  vord:maxValue "30"^^xsd:integer ;
  vord:hasScope vord:PerRequest ;
  vord:enforcement vord:RejectRequest ;
  vord:hardRestriction true .
