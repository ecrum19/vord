Scope Concepts

Instances of vord:Scope and skos:Concept used to indicate where a restriction is evaluated.

TermPreferred LabelClassificationDescription
vord:GlobalScope Global vord:Scope The restriction is shared across all traffic handled by the endpoint instance or cluster.
vord:PerAPIKey Per API Key vord:Scope The restriction is enforced independently for each API key credential.
vord:PerClientIP Per Client IP vord:Scope The restriction is enforced independently for each client IP address.
vord:PerRequest Per Request vord:Scope The restriction is evaluated within a single incoming request or query execution.
vord:PerUser Per User vord:Scope The restriction is enforced independently for each authenticated user identity.

Enforcement Mode Concepts

Instances of vord:EnforcementMode and skos:Concept describing operational behavior at restriction boundaries.

TermPreferred LabelClassificationDescription
vord:DegradeQuality Degrade Quality vord:EnforcementMode The endpoint continues serving requests with reduced quality of service.
vord:QueueRequest Queue Request vord:EnforcementMode The endpoint queues requests instead of executing immediately when capacity is constrained.
vord:RejectRequest Reject Request vord:EnforcementMode The endpoint rejects requests that violate the restriction.
vord:ThrottleResponse Throttle Response vord:EnforcementMode The endpoint slows processing or response delivery under limiting conditions.
vord:TruncateResult Truncate Result vord:EnforcementMode The endpoint returns a partial result when the restriction is reached.
