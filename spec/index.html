This draft defines a practical usage profile for https://example.com/vord# (VoRD) so SPARQL endpoint maintainers can advertise machine-readable live endpoint limits to users.

This is an unofficial proposal.

Terminology

The key words MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL are to be interpreted as described in RFC 2119 and RFC 8174.

Conformance

A conforming VoRD publisher satisfies all normative requirements in this document.

PREFIX sd:   <http://www.w3.org/ns/sparql-service-description#>
PREFIX vord: <https://w3id.org/vord#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>

Publishing Model

A service description resource of type sd:Service MUST link to one or more limits using vord:hasLimit.

Every quantitative limit MUST include:

  • a vord:Limit and a concrete limit subclass.
  • vord:metric and vord:maxValue.
  • vord:hasScope, vord:enforcement, and vord:hardLimit.

Federation capability MUST use class vord:FederationSupported and boolean property vord:federationSupported.

Priority Profile for Maintainers

  • MUST: vord:RateLimit, vord:ResultSizeLimit, vord:ResponseTimeLimit, vord:FederationSupported.
  • SHOULD: vord:ConcurrentRequestsLimit, vord:QuotaLimit.
  • MAY: vord:ServerLoadLimit, vord:CostModelLimit.

Minimal Example

@prefix ex:   <https://example.org/sparql/> .
@prefix sd:   <http://www.w3.org/ns/sparql-service-description#> .
@prefix vord: <https://w3id.org/vord#> .
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#> .

ex:service a sd:Service ;
  sd:endpoint <https://example.org/sparql> ;
  vord:hasLimit ex:rate, ex:resultSize, ex:responseTime, ex:federationSupport .

ex:rate a vord:Limit, vord:RateLimit ;
  vord:metric vord:requestsPerWindow ;
  vord:maxValue "60"^^xsd:integer ;
  vord:windowDuration "PT1M"^^xsd:duration ;
  vord:hasScope vord:PerClientIP ;
  vord:enforcement vord:RejectRequest ;
  vord:hardLimit true .

ex:resultSize a vord:Limit, vord:ResultSizeLimit ;
  vord:metric vord:resultBindings ;
  vord:maxValue "50000"^^xsd:integer ;
  vord:hasScope vord:PerRequest ;
  vord:enforcement vord:TruncateResult ;
  vord:hardLimit true .

ex:responseTimeMetric a vord:Metric .

ex:responseTime a vord:Limit, vord:ResponseTimeLimit ;
  vord:metric ex:responseTimeMetric ;
  vord:maxValue "30"^^xsd:integer ;
  vord:hasScope vord:PerRequest ;
  vord:enforcement vord:RejectRequest ;
  vord:hardLimit true .

ex:federationSupport a vord:Limit, vord:FederationSupported ;
  vord:federationSupported true ;
  vord:hasScope vord:GlobalScope ;
  vord:enforcement vord:RejectRequest ;
  vord:hardLimit true .
